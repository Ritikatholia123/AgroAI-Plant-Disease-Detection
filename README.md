# 🌿 AgroAI

## AI Powered Plant Disease Detection System

AgroAI is a deep learning based web application that detects plant diseases from leaf images using a CNN model built with TensorFlow and provides complete farming recommendations.

## Features

- 🌿 Plant Disease Detection
- 📷 Image Upload
- 📊 Prediction Confidence
- 💊 Treatment Recommendation
- 🌾 Fertilizer Suggestion
- 🧪 Pesticide Recommendation
- 🌦 Weather Advice
- 💧 Water Recommendation
- 🌱 Soil Recommendation
- ☀ Sunlight Requirement
- 🌿 Organic Control
- 🏛 Government Advice
- 📄 PDF Report Generation

## Technologies Used

- Python
- TensorFlow
- Streamlit
- NumPy
- Pandas
- Pillow
- ReportLab
